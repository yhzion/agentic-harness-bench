# 품질 게이트

## STEP 게이트

각 STEP 완료 전 다음 조건을 모두 만족해야 합니다.

```txt
해당 STEP 테스트 통과
현재 STEP의 완료 조건 만족
수정 가능 파일 외 변경 없음
함수 시그니처 변경 없음
public interface 변경 없음
스펙 외 기능 추가 없음
```

## 중간 게이트

도메인 레이어가 끝났을 때:

```txt
도메인 테스트 전체 통과
도메인 함수가 UI/Storage를 import하지 않음
타입 체크 통과
```

저장소 레이어가 끝났을 때:

```txt
storage 테스트 전체 통과
잘못된 저장 데이터 복구 테스트 통과
타입 체크 통과
```

UI 레이어가 끝났을 때:

```txt
컴포넌트 렌더링 테스트 통과
주요 이벤트 테스트 통과
접근성 기본 조건 통과
```
