# 개발 스펙

이 문서는 에이전트가 따라야 하는 최상위 스펙입니다.
스펙에 없는 기능은 구현하지 않습니다.

## 예시: Todo 앱 MVP

### 목적

사용자가 할일을 추가, 조회, 완료 처리, 수정, 삭제할 수 있는 앱을 구현한다.

### 기술 스택

이 항목은 실제 프로젝트에 맞게 수정한다.

```txt
Frontend: 프로젝트에서 이미 정한 프레임워크
Language: TypeScript
Storage: LocalStorage
Test: 프로젝트에서 이미 정한 테스트 도구
Preview: 사용자에게 Preview URL 제공까지
```

### 도메인 규칙

```txt
Todo는 id, title, completed, createdAt, updatedAt을 가진다.
title은 빈 문자열일 수 없다.
title은 앞뒤 공백을 제거한 뒤 저장한다.
completed 기본값은 false다.
createdAt과 updatedAt은 생성 시점에 같은 값이다.
Todo 완료 상태 변경 시 updatedAt을 갱신한다.
Todo 제목 수정 시 updatedAt을 갱신한다.
Todo 삭제 시 목록에서 제거한다.
```

### 저장소 규칙

```txt
LocalStorage에 Todo 배열을 저장한다.
저장된 값이 없으면 빈 배열을 반환한다.
잘못된 JSON이면 빈 배열을 반환한다.
잘못된 Todo 구조는 복원하지 않는다.
```

### UI 규칙

```txt
사용자는 입력창에 제목을 입력하고 할일을 추가할 수 있다.
Enter 키로도 할일을 추가할 수 있다.
빈 제목은 추가할 수 없다.
사용자는 체크박스로 완료 상태를 변경할 수 있다.
사용자는 제목을 수정할 수 있다.
사용자는 할일을 삭제할 수 있다.
전체, 미완료, 완료 필터를 사용할 수 있다.
빈 목록일 때 안내 메시지를 표시한다.
```

### 제외 기능

```txt
서버 API 연동은 하지 않는다.
사용자 로그인은 구현하지 않는다.
드래그 앤 드롭 정렬은 구현하지 않는다.
마감일, 우선순위는 구현하지 않는다.
```
