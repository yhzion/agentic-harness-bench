# Agentic 구현 Runbook

## 에이전트 실행 전 준비

1. 스펙이 확정되었는지 확인한다.
2. 타입, 인터페이스, 함수 시그니처가 정의되었는지 확인한다.
3. STEP 파일이 충분히 작은지 확인한다.
4. progress.json의 currentStep이 올바른지 확인한다.
5. 프로젝트의 테스트, 타입 체크, 린트, 빌드 명령이 실행되는지 확인한다.

## 에이전트 실행 중

에이전트는 다음만 수행한다.

```txt
현재 STEP 읽기
허용 파일 확인
테스트 작성 또는 확인
구현
검증 명령 실행
실패 시 수정
성공 시 progress 갱신
```

## 사람이 개입해야 하는 경우

```txt
같은 STEP에서 3회 실패
스펙 자체가 모호함
테스트와 스펙이 충돌함
함수 시그니처 변경이 필요함
의존성 방향이 깨짐
```

## 실패 보고서 형식

`.agentic/reports/failure-report.md`에 다음을 작성한다.

```txt
실패 STEP
실패한 명령
관찰된 에러
시도한 수정
추정 원인
사람이 결정해야 할 사항
```
